# CAVEN visual language

Kinetic calm: a near-black instrument board with one luminous living object at its centre. The interface is low-density and almost silent; cyan communicates presence and action, while amber is held back for thought and attention.

- **Type:** Manrope for clear, warm UI reading; DM Mono for small system labels and timing.
- **Ground:** #06090d with a softened charcoal radial vignette. Panels are translucent blue-black glass, never opaque cards.
- **Signal:** cyan #55dbe4 for active controls and progress; amber #f5b642 for thinking/attention; mint #7ce6bd for completion.
- **Structure:** hairline cyan-grey borders and short corner brackets. Rounded geometry is used in the core and controls; panels are restrained 14px rectangles.
- **Motion:** slow, physically quiet, stateful. A user action gets one decisive outward response, then returns to stillness. Respect reduced motion.
